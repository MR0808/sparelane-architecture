# Sparelane Architecture

Architecture-as-code repository for the Sparelane payment reliability platform.

## Technology

Architecture diagrams are defined using LikeC4.

## Run locally

```bash
npm install
npm run dev
Build
npm run build

The static architecture site is generated into /dist.
```
